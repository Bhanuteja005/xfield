| Area | Shipped behavior | Remaining |
| --- | --- | --- |
| Explore, tools, presets | Searchable galleries, tool navigation, creative directions | Full original catalog and autoplay video assets |

| Library | Upload, rename, favorite, folders, download, ownership checks | Bulk actions and folder deletion |

| Marketing | Brand/product brief, direction selection, concept handoff and text export | Generated campaign images/video bundles |
| Community | Curated samples and explicitly published workspace assets | Comments, follows and moderation infrastructure |
| Audio | Browser voice preview | Provider output and audio export |
| Assistant | Explicit template-based planning | AI chat integration |
| Account | Guest continuity, profile and API connection | Recoverable user accounts, cross-device sync |
| Plans | Informational plan comparison | Payments and subscription management |
| Help | In-app usage guides | Original academy/course library |

This is a working core product rebuild. Inventorying every reference screen does not mean every original feature is implemented. Detailed original-provider use was limited by authentication/payment requirements; no claim is made that every original paid flow was exercised.
